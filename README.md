# Исходники фронтенда игры Легион

[Сама игра](https://play.multidonate.ru/)

[ТГ канал](https://t.me/) с описанием обновлений и разбором найденного.

## Зачем?

Это общий репозиторий для автоматического отслеживания обновлений игры

Все, кому интересны обновления могут зайти сюда и посмотреть точный diff межу версиями в течение 20 минут

## А что, если появятся новые файлы?

[Список ссылок](files.link) измеряется врчную владельцем репозитория

Ссылки собираются со всех известных JS файлов, что обеспечивает почти полное покрытие при текущей архитектуре
